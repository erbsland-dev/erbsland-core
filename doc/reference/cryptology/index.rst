**********
Cryptology
**********

The cryptology API provides algorithms and stateful operations for protecting data, representing cryptographic choices,
and evolving stored formats as security policy changes.
The following reference pages summarize the available types; the :doc:`/topics/cryptology/index` pages provide the
primary usage and security guidance.
