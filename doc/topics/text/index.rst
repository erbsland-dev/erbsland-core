****
Text
****

Text sits at the boundary of almost every application: it arrives from users and protocols, moves through parsers and
validators, and leaves again as formatted or encoded output.
Erbsland Core gives these tasks a shared Unicode model, safe owning values, and focused tools for the places where text
must be edited or constructed.

Start with :doc:`overview` for a guided tour of the domain.
It connects the individual topics and helps you find the page that matches the problem you are solving.
