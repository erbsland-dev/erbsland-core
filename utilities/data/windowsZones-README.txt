Unicode CLDR Windows Time-Zone Mapping
======================================

This directory contains a snapshot of ``windowsZones.xml`` from Unicode CLDR release 48.

Source:
https://raw.githubusercontent.com/unicode-org/cldr/release-48/common/supplemental/windowsZones.xml

The snapshot is used by ``utilities/run.py generate_time_zone_data``. Keeping the source data in the repository
makes time-zone generation deterministic and independent of network availability.

CLDR data files are provided by the Unicode Consortium under the Unicode License Agreement. The original copyright
and terms-of-use notice is retained in ``windowsZones.xml``.
