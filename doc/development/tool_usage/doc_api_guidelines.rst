***********************
Validate API Guidelines
***********************

Validate domain-specific API guideline structure and pattern syntax after changing a domain's naming rules.
The shared ``common.rst`` page is intentionally excluded.

.. code-block:: console

    ./erbsland-core-tool doc-api-guidelines

Review diagnostics with their page and line number, correct the rules, and rerun the command.
The command does not write files or require individual configuration.

See :doc:`usage` for shared invocation options and
:doc:`../tool_reference/documentation_tools_reference` for the technical contracts.
