*******************
Regular Expressions
*******************

Erbsland Core includes a regular expression engine with Unicode-aware matching, configurable compatibility features, and
diagnostics tools for inspecting compiled programs.
These pages describe the supported pattern syntax and the assembler used for advanced diagnostics and testing.
For the public C++ interface, see :doc:`/reference/re/index`.
