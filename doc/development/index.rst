Development
===========

If you are writing an extension, start with :doc:`extension/index`.
It follows a small library from its first public header through building, testing, and maintaining it alongside Core.

If you want to use Erbsland Core in your own application, start with
:doc:`/get-started/index` or :doc:`/usage/index` instead.

For work on Core itself, start with :doc:`setup`.
It prepares the build environment and installs the maintenance tool so you can run it when needed.
Developing that tool is a separate, optional step described in :doc:`tool_dev/build_and_test`.
