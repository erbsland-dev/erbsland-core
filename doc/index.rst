***************************
Erbsland Core Documentation
***************************

**Erbsland Core** is a base library that provides a rich API and platform abstraction for user code.

The library provides native support for **Linux**, **macOS**, and **Windows**.

- Write user-code once and compile it everywhere.
- Avoid boilerplate code.
- Make use of a large feature set and a consistent API over all data types.
