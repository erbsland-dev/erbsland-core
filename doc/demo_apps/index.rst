***************************
Demo Applications Explained
***************************

These walkthroughs explain how complete demo applications fit together: where work runs, who owns its state, how results
move, and what brings the program to an end.
Each follows the parts of its application that teach useful concepts, with source excerpts and bounded example runs.
For the general API concepts behind a design, follow the links to :doc:`/topics/index`.

The applications live under ``demos/<domain>/apps``.
Runnable snippet collections and compile-only templates serve the topic pages; this section focuses on whole
applications.
