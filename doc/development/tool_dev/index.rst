Develop the Maintenance Tool
****************************

The maintenance tool is a C++ application built with Erbsland Core's public API.
These pages explain how its framework fits together and how to add commands and shared data sources.

Start with :doc:`build_and_test`, then read the :doc:`framework` overview.
Use the authoring guides when adding functionality and the :doc:`../tool_reference/index` for detailed behavior.
For running existing commands, see :doc:`../tool_usage/index`.
